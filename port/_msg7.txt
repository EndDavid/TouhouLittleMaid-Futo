Port the trumpet (first of the four search tools)

The search-tool group is four items and three of them need brand-new client GUIs,
so this lands the one that does not: the trumpet. Book is now 43 entries / 3
categories, validator 0 problems.

Behaviour, copied from upstream ItemTrumpet:
- hold right click to charge (use duration 100, UseAnim.BOW)
- on release, if timeLeft >= 20 the server teleports every maid the player owns on
  that ServerLevel to a +-1 block offset around them, then adds a 200 tick cooldown
- setHomeModeEnable(false) before the teleport, otherwise a maid on "home mode"
  immediately walks back and it looks like the tool did nothing
- afterwards it consults MaidWorldData: any maids still recorded on unloaded chunks
  produce message.touhou_little_maid.trumpet.unloaded_maid, i.e. "there are N more,
  use the Red Fox Scroll". Unloaded chunks are a hard limit, not an omission: those
  entities are not in memory, so the count message is the only useful thing to say.
- TriggerType.USE_TRUMPET is fired for the advancement (that constant and
  InitTrigger.MAID_EVENT already existed, so the trigger does work here)

Deviations, both forced:
- EntityMaid.TYPE does not exist in this port (it is a Forge-side constant); the
  registered type is InitEntities.MAID, so getEntities uses that.
- sendMessage(Component, UUID) was removed in 1.18.2; displayClientMessage is used
  instead (same as the saddle diagnostic added earlier).

Deliberately kept verbatim even though it reads oddly: the gate is
"timeLeft >= MIN_USE_DURATION", which in 1.18.2 means "charged at least 80 of the
100 ticks", not "1 second". Upstream ships that exact comparison; silently
"fixing" it would change the feel of the item.

Also in this commit: altar recipe craft_trumpet (forge ingot tags translated to
c:gold_ingots / c:iron_ingots, note_block kept), the three lang keys plus the
message, other/trumpet.json restored, and trumpet added to validate-book.ps1.

Verified: gradlew build green, jar 38,913,757 bytes, deployed with a matching
SHA-256, validate-book.ps1 entries=43 categories=3 problems=0.
